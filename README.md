# Personal Automation Scripts

This repository contains a collection of small automation scripts I use to streamline my personal workflow and manage my server. These are primarily command-line tools and utilities written in various languages, mostly C++ and Bash.

## Usage

Each script is standalone. Check the individual file headers for setup instructions and usage examples.

## Notes

- Scripts are intended for personal use and may require environment-specific paths or configurations.  
- Contributions are not expected, but feedback is welcome if you want to adapt them for your own use.
